# 거짓말하는 튜토리얼 · Deceptive Guide

캐릭터가 기계 세계를 이동하는 한국어 포인트 앤 클릭 어드벤처입니다. 첫 화면에서 바로 플레이합니다.

## 포함된 구현
- 50개 연결 스테이지, 10개 원본 일러스트 지역 배경, 89개 데이터 기반 퍼즐 단계
- 바닥 클릭·방향키 이동, 동행 가이드, 조사 기록, 인벤토리 도구 사용
- 선택, 순서, 무게 조합, 기계 주기, 지연 반응 퍼즐과 실패 복구
- 11개 적응형 스테이지의 고정 seed·가이드 변형과 저장
- 네 가지 결말. 숨겨진 관리자 결말은 기억 조각 10개로 해금
- 로컬 저장 및 IndexedDB 백업, 수동 저장·복원, 지역 재방문
- 서비스 워커, 설치용 manifest, 지역별·전체 오프라인 다운로드
- 키보드·터치, 고대비, 큰 글자, 동작 감소, 시각적 타이밍 단서
- 개발 모드에서만 설정 하단에 Stage Selector 표시

## 실행 및 검증
- 개발: `npm run dev`
- 빌드: `npm run build`
- 데이터 검증 (Node 24): `node scripts/validate-stages.ts`
- 단위 테스트: `npx vitest run src/game/game.test.ts`
- E2E 브라우저 설치: `npx playwright install chromium`
- E2E: `npx playwright test`

패키지 스크립트와 기존 Vite 설정을 변경하지 않았으므로 `pnpm validate:stages`라는 별도 스크립트는 등록하지 않았습니다.

## 조작
바닥 클릭 또는 방향키로 이동합니다. Tab과 Enter로 모든 사물에 접근할 수 있습니다. E 조사, H 힌트, I 가방, J 정비 일지, M 지도, Escape 닫기. Space는 바닥/장면에 포커스가 있을 때 조사 표시를 전환합니다. 도구는 줍고 인벤토리에서 선택한 뒤 장면 속 대상에 사용합니다.

## 범위와 검증 상태
이 구현은 요청된 장편 디자인을 공통 장면 엔진과 89개 퍼즐 단계로 축약한 플레이 가능한 버전입니다. 6~9시간 분량의 수작업 장면 연출, 19종 캐릭터별 완전한 애니메이션 시트, 모든 스테이지의 별도 카메라·다층 길찾기, 완전한 영어 대사 번역은 제공하지 않습니다. 영어는 UI와 스테이지 제목 및 확장 가능한 데이터 구조를 제공합니다.

프로덕션 빌드는 확인했습니다. 테스트 파일은 포함했지만 이 작업 환경에서는 Vitest·Playwright를 실행하지 않았으며, 50개 스테이지의 실제 브라우저 완주나 성능·접근성 감사를 완료했다고 주장하지 않습니다.

현재 React 19, Vite 7, TypeScript 5의 기존 안정 환경을 유지했습니다. PixiJS 8/@pixi/react는 배경 입자 렌더링에, SVG·DOM은 캐릭터와 접근 가능한 장면 조작에 사용합니다. WebGL을 사용할 수 없어도 핵심 장면은 DOM으로 유지됩니다. 원격 LLM과 유료 API는 사용하지 않습니다.
